Configuración inicial

Para usar el gestor colaborativo necesitas conectarlo a tu base de datos Supabase. Solo se hace una vez.

Pasos previos:
1. Crea una cuenta gratis en supabase.com
2. Crea un proyecto nuevo
3. Ejecuta el SQL de la guía en el SQL Editor
4. Copia la URL y la clave anon de Settings → API
Settings → API → Project URL
Settings → API → Project API Keys → anon public
